# iomad-lang-fr

Traduction française personnalisée pour **IOMAD 403**.

## Branches
- `iomad-403` : compatible IOMAD 403 ✅
- `iomad-405` : à venir
- `iomad-500` : à venir

## Installation (IOMAD 403)
Cloner la branche correspondante dans le dossier moodledata :

```bash
cd /var/moodledata/lang
git clone -b iomad-403 https://github.com/ericfalcon/iomad-lang-fr.git fr_local
``
